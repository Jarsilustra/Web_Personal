1. Web Personal – Proyecto Final Bootcamp TalentoTech

---

2. 📌 Descripción (Español)

Este repositorio contiene el desarrollo de mi página web personal, creada como **proyecto final del Bootcamp de Desarrollo Web Fullstack Básico** impartido por 
**TalentoTech Colombia**.

El propósito principal de este proyecto es **poner en práctica los conocimientos adquiridos en HTML, CSS y JavaScript**, aplicando buenas prácticas de maquetación, 
diseño responsive y estructura de proyecto. Además, este sitio funciona como mi portafolio personal para mostrar mis habilidades como ilustrador y desarrollador frontend 
en formación.

---

3. 🎯 Objetivos del proyecto

- Desarrollar una página web funcional y atractiva desde cero.  
- Implementar diseño responsive adaptable a diferentes dispositivos.  
- Integrar secciones clave para un portafolio personal (about, servicios, portafolio, contacto).  
- Demostrar las habilidades adquiridas en el Bootcamp en un entorno práctico.  

---

4. 🛠 Tecnologías utilizadas

- **HTML5** – Estructura del contenido.  
- **CSS3** – Estilos, diseño responsivo y animaciones.  
- **JavaScript (Vanilla)** – Interactividad básica (menús, sliders, etc.).  
- **Git & GitHub** – Control de versiones y despliegue.

7. 🖥 Instalación y ejecución

Si deseas clonar y ejecutar este proyecto en tu computadora:

1. Clona el repositorio:
     ```bash
       git clone https://github.com/Jarsilustra/Web_Personal.git

2. Ingresa al directorio del proyecto:

       cd Web_Personal

3. Abre el archivo index.html en tu navegador preferido:

        Haz doble clic en el archivo
        o
        Usa una extensión como Live Server en VS Code para visualizarlo localmente.
